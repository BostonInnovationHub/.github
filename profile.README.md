# Boston Innovation Hub

> **Frontier Transformation starts here.**

The Boston Innovation Hub is a collaborative space where customers design, build, and validate solutions that drive real business transformation. At the Hub, Microsoft engineers work side-by-side with your team to apply AI, cloud, and modern development practices to your most important challenges.

---

## 🌐 Website

This repository hosts the public landing page for the Boston Innovation Hub at:
**[bostoninnovationhub.github.io](https://bostoninnovationhub.github.io)**

The site features:
- **Hero section** — overview of the Hub's mission and value proposition
- **Public Repositories** — a live-loaded gallery of the Hub's open-source work pulled directly from the GitHub org
- **Navigation & Footer** — links to the GitHub org and Microsoft.com

## 🛠️ Local Development

The site is a static HTML/CSS/JS site with no build step required.

```bash
# Clone the repo
git clone https://github.com/BostonInnovationHub/bostoninnovationhub.github.io.git
cd bostoninnovationhub.github.io

# Open directly in a browser, or serve locally with any static server
npx serve .
```
